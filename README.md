# 🧠 NeuroScan AI — Brain Tumor MRI Classification

NeuroScan AI is a Deep Learning based medical imaging project that detects and classifies brain tumors from MRI scans using CNNs and Transfer Learning.

## 🚀 Features

- Brain MRI Tumor Classification
- MobileNetV2 Transfer Learning
- Flask Web Application
- MRI Upload & Prediction
- Responsive UI
- Real-time Confidence Scores

## 🧬 Tumor Classes

- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Flask
- OpenCV
- HTML, CSS, JavaScript

Dataset: Brain MRI Images for Brain Tumor Detection (Kaggle)
https://www.kaggle.com/datasets/navoneel/brain-mri-images-for-brain-tumor-detection/data

## 📊 Model Accuracy

Accuracy: 75.56%
